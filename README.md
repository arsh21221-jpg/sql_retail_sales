# SQL Retail Sales Analysis

## Project Overview

This project analyzes retail sales data using SQL. It includes database creation, data cleaning, data exploration, and business analysis queries to generate meaningful insights from retail transactions.

## Tools Used

- MySQL
- SQL

## Key Tasks

- Database Creation
- Data Cleaning
- Data Exploration
- Sales Analysis
- Customer Analysis
- Business Insights

## Business Questions Solved

- Retrieve sales for a specific date.
- Analyze Clothing sales in November 2022.
- Calculate total sales by category.
- Find the average age of Beauty customers.
- Retrieve transactions with sales greater than 1000.
- Count transactions by gender and category.
- Identify the top 5 customers by total sales.
- Count unique customers by category.
